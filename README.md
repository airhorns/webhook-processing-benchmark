# Webhook Processing Benchmark

Compare Ruby, Elixir, Go, and Rust on a stateless Shopify-style webhook workload:

1. Receive `POST /webhook` with `X-Shopify-Hmac-Sha256`
2. Verify HMAC-SHA256(secret, body) against the header (constant-time)
3. Parse the JSON body
4. For each entry in `variants[]`, produce an object where every string value is upcased, serialize back to JSON, and write JSON + newline to an open `/dev/null` fd
5. Return `200 OK`, empty body

Caps each server to 1 or 4 cores via worker-count config (no Docker). Load is generated by a tokio + hyper client that's deliberately overpowered for any of the servers.

## Layout

- `client/` — Rust + tokio + hyper load generator
- `servers/{ruby,elixir,go,rust}/` — server implementations
- `shared/payload.json`, `shared/secret.txt` — fixtures shared by client + servers
- `bench/run.sh` — orchestrate one run, write results JSON
- `bench/results/` — per-run JSON
- `RESULTS.md` — comparison summary
- `.claude/skills/load-test/` — Claude Code skill for driving benches

## Quick start

See the load-test skill (`.claude/skills/load-test/SKILL.md`) or invoke `/load-test` inside Claude Code for the canonical build & run instructions.

Host used for the included results: Apple M4 Pro (12 physical cores), macOS 26.4.
